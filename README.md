# Software Quality Assurance Project

โครงงานรายวิชา **Software Quality Assurance (SQA)**
สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

---

## เกี่ยวกับโครงงาน

โครงงานนี้จัดทำขึ้นเพื่อศึกษาและประยุกต์ใช้แนวคิดด้าน **Software Quality Assurance และ Software Testing** โดยมุ่งเน้นการทดสอบซอฟต์แวร์แบบอัตโนมัติ และการประเมินประสิทธิภาพของเทคนิคการสร้าง Test Case

ในการทดลองใช้ชุดข้อมูล **Defects4J** ซึ่งเป็น Benchmark สำหรับการทดสอบโปรแกรมภาษา Java ที่มี Bug จริงจากโครงการซอฟต์แวร์ต่าง ๆ

โครงงานจะทำการทดลองและเปรียบเทียบวิธีการสร้าง Test Case

---

## วัตถุประสงค์

1. ศึกษาหลักการและแนวคิดของ Software Quality Assurance
2. ศึกษาเทคนิคและเครื่องมือสำหรับการทดสอบซอฟต์แวร์แบบอัตโนมัติ
3. ทดลองสร้าง Test Case ด้วยเครื่องมือและอัลกอริทึมที่แตกต่างกัน
4. ประเมินประสิทธิภาพของ Test Case ที่สร้างขึ้น
5. เปรียบเทียบความสามารถในการตรวจจับ Bug ของแต่ละวิธี
6. วิเคราะห์ผลการทดลองจากโครงการต่าง ๆ ใน Defects4J

---

## Defects4J

โครงงานนี้ใช้ **Defects4J** เป็น Benchmark ในการทดลอง

แต่ละ Bug จะถูกนำมาทดสอบด้วยวิธีการที่กำหนด และเก็บผลลัพธ์เพื่อนำมาเปรียบเทียบ

---

## ตัวชี้วัดที่ใช้ในการประเมิน

การประเมินผลการทดลองพิจารณาจากตัวชี้วัด เช่น

### 1. Code Coverage

วัดสัดส่วนของโค้ดที่ Test Case สามารถทำงานผ่านได้ เช่น

- Line Coverage
- Branch Coverage
- Method Coverage

### 2. Fault Detection

วัดความสามารถของ Test Case ในการตรวจจับ Bug ที่อยู่ใน Defects4J

### 3. จำนวน Test Case

วัดจำนวน Test Case ที่สามารถสร้างขึ้นได้ภายในเวลาที่กำหนด

### 4. เวลาในการสร้าง Test Case

วัดระยะเวลาที่แต่ละเทคนิคใช้ในการสร้าง Test Case

### 5. จำนวนการทำงานของโปรแกรม

สำหรับการทดลองแบบ Fuzzing จะเก็บข้อมูลจำนวน Execution และ Valid Execution เพื่อใช้ในการวิเคราะห์ผล
